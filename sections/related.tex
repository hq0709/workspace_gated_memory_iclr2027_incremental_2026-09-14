\section{Background and Related Work}
\label{sec:related}

\paragraph{Memory systems and evaluation.}
Generative Agents combines ratings of importance with recency and
relevance for retrieval \citep{park2023generative}. MemoryBank, MemGPT,
Mem0 and A-MEM provide persistence, memory operations and organization
\citep{zhong2023memorybank,packer2023memgpt,mem0,amem2025}.
LoCoMo and LongMemEval evaluate memory over long conversations
\citep{maharana2024locomo,wu2025longmemeval}.

\paragraph{Admission criteria.}
ConsistencyGate filters candidates by self-consistent support in the
source context \citep{consistencygate2026}, while A-MAC combines LLM
assessment with textual support and memory attributes \citep{amac2026}.
A multi-factor value model optimizes evidence retention
\citep{valuemodel2026}, and Causal Memory Intervention scores answers to
a known request under memory interventions \citep{cmi2026}. SDA instead
draws targets from the frozen model's own workspace readout and output
likelihood.

\paragraph{Learned memory management.}
Nemori distills interaction sequences into memory using prediction error
\citep{nemori2026}. MemCon learns a policy for retrieval, consolidation
and forgetting \citep{memcon2026}, while AgeMem trains memory tool
actions with reinforcement learning \citep{agemem2026}. The survey of
\citet{hu2025memorysurvey} situates these approaches within memory
systems.

\paragraph{Internal signals and representation decoding.}
EM-LLM, SirLLM and Titans use surprisal, entropy and gradient-based
surprise for memory
\citep{fostiropoulos2024emllm,yao2024sirllm,behrouz2025titans}.
The logit lens, a J-lens with the identity map, decodes internal
representations
\citep{nostalgebraist2020logitlens,anthropic2026workspace}, as do tuned
lenses, Future Lens and Patchscopes
\citep{belrose2023tuned,pal2023futurelens,ghandeharioun2024patchscopes}.
SDA's workspace readout applies the logit lens across layers
(\S\ref{sec:teacher}).

\paragraph{Memory distillation and self-distillation.}
Knowledge distillation transfers teacher predictions to a student,
including between models of the same architecture
\citep{hinton2015distilling,furlanello2018bornagain}.
TMEM writes distilled experience into low-rank weights
\citep{tmem2026}, while Agent Memory Distillation transfers a larger
teacher agent's trajectories into structured memory for a smaller
student \citep{amd2026}. Unlike TMEM and Agent Memory Distillation,
we use the same model as teacher and student.

\paragraph{Internal information and model reports.}
Internal states can predict correctness beyond expressed confidence
\citep{kadavath2022know,azaria2023internal,orgad2024llmsknow}.
Stated reasoning can omit influences on an answer
\citep{turpin2023cot}, and salience can be poorly reported
\citep{trienes2025salience}. Introspection training teaches models to
predict their behavior \citep{binder2024introspection}.
