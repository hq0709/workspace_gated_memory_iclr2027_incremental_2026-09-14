\section{Introduction}
\label{sec:intro}

An LLM agent must choose what to remember before it knows the next
question. The useful concept is often an inference that the passage
never states. A description of a landmark can identify a city without
naming it. Remembering that city preserves the link to a later question
about the local language. Once the passage leaves the context, the
agent's answer depends on which inferences survived admission to memory.

Memory systems make this choice through judgments the model expresses.
They ask for importance ratings or admit-or-discard decisions
\citep{park2023generative}, or apply criteria built on context support
\citep{amac2026,consistencygate2026}. In each case, the passage provides
the evidence for admission. An agent also needs to preserve what it
inferred from the passage. This creates a gap between recognizing an
inference during reading and selecting it for later use. A memory system
can discard the useful concept even when the model has identified it.

We score the same importance report on controlled pools that keep each episode's useful concept fixed and vary
which candidates the passage states.
A drop in AUC therefore isolates the effect of provenance: whether the
passage states a candidate. The report's useful-concept AUC falls from
0.880--0.897 among unstated candidates alone to 0.658--0.736 on the
statedness-balanced pool and 0.322--0.427 on the standard pool. The
statedness-balanced pool states the useful concept in half the episodes.
In the standard pool, the useful concept is usually the unstated
candidate. The report thus ranks useful concepts below chance when they
compete with stated distractors. The 1-10 importance rating and published
criteria built on context support show the same preference for stated
candidates.

The model's workspace readout ranks the useful concept above chance on
that same standard pool. Its internal computation carries information
that its importance report fails to preserve. Naming the useful concept
in an otherwise unchanged episode raises AUC for both signals, with a
larger increase for the workspace readout (Figure~\ref{fig:hero}). These
controlled changes show how admission depends on the way a concept
appears in the passage.

Self-Distilled Admission (SDA) transfers the model's own candidate
rankings into its admission decision (Figure~\ref{fig:sda}). A frozen
model ranks each episode's candidates using its workspace readout and
output likelihood. It labels the top two candidates for admission, then
trains a LoRA adapter \citep{hu2021lora} on those labels through its own
importance prompt. Optimization uses only the passage, candidates, and
labels generated by the model. It uses no future question, reward, or
external teacher. We select the earliest checkpoint by validation
admission AUC on a development set with construction-assigned utility
labels.

SDA improves recall over the judgments used by existing memory systems.
On the primary statedness-balanced pool, it exceeds each model's own
importance report in 54 of 54 comparisons across models, seeds, and
memory budgets, and exceeds the 1-10 importance rating in 52 of 54
(Table~\ref{tab:balanced}). For Qwen3-8B at two stored concepts, SDA
adds 10.7 points of recall over the importance report and 5.2 over the
rating. ConsistencyGate, A-MAC, and Nemori fall below the untrained
report. SDA exceeds these published admission criteria by 14.1--27.8
points at the same memory budget
(Table~\ref{tab:balancedbaselines}).

The paired-passage battery tests whether the teacher uses the passage
to identify the useful concept. Only the passage distinguishes which
concept is useful. Across five models, removing the workspace readout from the teacher
costs 1.9 recall points at one stored concept
(Table~\ref{tab:crosspairpooled}). Both teacher signals contribute to
recall on this battery.

SDA serves as a plug-and-play adapter in a standard engine. It attaches
only to admission requests. The served Qwen3-8B adapter reaches
50.1\% recall on the standard pool at 242 candidates per second
(Table~\ref{tab:sdadeploy}).

Our contributions are:
\begin{itemize}
    \item \textbf{Provenance in importance judgments.} We show that
    importance judgments order candidates by whether the passage states
    them. Controlled pools separate this preference from usefulness,
    while the workspace readout tracks useful unstated inferences.
    \item \textbf{Plug-and-play SDA module.} SDA distills the model's
    workspace readout and output likelihood into its own importance
    prompt. The resulting adapter brings these rankings to admission
    requests through standard serving.
    \item \textbf{Results across models and memory settings.} Evaluation
    spans six models from three families, three seeds, three memory
    budgets, and five candidate pools. Comparisons with the importance
    report, ratings, and published admission criteria establish recall
    gains. Ablations on the paired-passage battery, where only the
    passage identifies the useful concept, show that both internal
    signals in SDA's teacher contribute to recall.
\end{itemize}
